# DrinkGo Project

This project contains both the backend and frontend for the DrinkGo application.

## Backend

The backend is a Java/Maven project. The source code is located in the `src/main/java` directory.

To run the backend, you can use the following Maven command:
```bash
mvn spring-boot:run
```

## Frontend

The frontend is a React application. All frontend code and documentation is located in the `frontend` directory.

To run the frontend, navigate to the `frontend` directory and run:
```bash
npm install
npm run dev
```

Please refer to the `frontend/README.md` for more detailed information about the frontend architecture and development process.
